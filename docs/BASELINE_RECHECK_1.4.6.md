# ChatGPT NET 1.4.6 对修订 Baseline 1.3 的逐章复核

**校对日期：** 2026-08-12

**校对范围：** 全部 Markdown、Functional Baseline 1.3 的 46 章/条款 1–500、Baseline Audit 逐条矩阵、Manual Acceptance 的 0 与 A–R。

**本版修订：** 第 83 条的多父独立性；第 205、206 条与 Manual Acceptance F88 按用户最终确认，以层级图最终清晰合理为先，再尽量缩小重排范围。

## 结论

46 章和 1–500 条编号仍连续。源码、静态审计、单元/压力测试以及 Chromium/Firefox 同流程浏览器回归均通过。Firefox 152.0.4 已在真实 `chatgpt.com` 验证标准 XPI 注入、页面让位、侧栏挂载与无扩展控制台错误；已登录历史会话鼠标拖放、Firefox 工具栏、隐私授权和原生文件对话框相关项目仍保留为生产环境边界，未伪报为自动通过。

## 最终判定

1.4.6 的功能实现与本文已明确记录的修订 Baseline 1.3 一致：保留用户落点是第一层尝试，但不以“少动”牺牲图形清晰度；必要时只整理受影响连通层级，绝不波及无关内容。
