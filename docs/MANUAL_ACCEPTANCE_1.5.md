# ChatGPT NET 1.5.0 — Windows Firefox 实机验收清单

**目标环境：** Windows Firefox 152+，当前生产 ChatGPT。

**需求依据：** Functional Baseline 1.5；未被替换的 1.3 验收项继续有效。

## A. 位置意图

- [x] 无关系节点释放到空白处后停在释放点或最近合法点，无关节点与线路不动。
- [x] 解除父关系只改结构；随后移动按手动落点，不自动归队。
- [x] 已关联节点释放到空白处不改变关系，不整理层级，只更新直接相关线路。
- [x] 独立子树根节点移动时，全部节点和内部线路使用同一平移量。
- [x] 共享下游仍有外部父节点时，不把它当作独立子树拉走。
- [x] 无合法邻近位置时恢复操作前状态并显示 1.5 指定提示。

## B. 关系意图与布局

- [x] 单节点拖到目标节点，建立父→子关系并自动排列受影响连通层级。
- [x] 父节点在上、子节点在下；同层横排；父节点位于直接子节点组合中心上方。
- [x] 共同父/共同子只在合法端附近共享短主干；无共同端线路不共享、不交叉。
- [x] 关系释放的横向位置能提示新增兄弟插入左、中、右，既有兄弟顺序稳定。
- [x] 合法第二父使合并层级形成清楚 DAG；共同子保持在父组合下方。
- [x] 两个拟议父互为祖先/后代时原子拒绝，结构与坐标不变。
- [x] 批量无父节点成为共同父的平级子节点，保留稳定左右顺序且一次提交。
- [x] 语义合法但有限画布无合理布局时，关系与坐标整体失败。
- [x] 新关系和全部自动排列只占一步撤回；撤回/重做同时恢复结构和坐标。

## C. 稳定性与无关内容

- [x] 新关系只移动受影响连通层级，不移动自由节点或其他连通层级。
- [x] 解除关系不触发整理，不移动幸存节点。
- [x] 选择、悬停、平移、缩放、改色、调整侧栏和移动无关节点不改变已有层级坐标与顺序。
- [x] 节点和 SVG 关系线按实体/关系 ID 复用，热交互不全量重建 DOM。
- [x] 同一结构、稳定顺序和障碍条件重复计算结果一致。

## D. 备忘录、正文和项目迁移

- [x] 画布节点进入备忘录；从备忘录拖回空白处成为释放点附近的独立根节点，不恢复旧关系。
- [x] 画布滚轮、平移和节点拖动不带动 ChatGPT 正文滚动。
- [x] 正文锚点、颜色、搜索、高亮、导入导出和分支规则继续通过 1.3 回归门槛。
- [x] 项目 A → 项目 B → 移出项目的三段路径保持同一 `conversationId`、实体集合和世界坐标。
- [x] 新 `conversationId` 不依据标题或正文相似度猜测迁移。

## E. 性能、资源和发行包

- [x] 500 节点核心数据与 360 关系路由压力测试通过。
- [x] Firefox 真实 XPI 交互无持续卡顿、闪烁或拖慢扩展提示。
- [x] Firefox 5 秒空闲 CPU 增量为 0.078125 秒，空闲态工作集约 340 MB，未观察到持续 CPU 占用。
- [x] `web-ext lint` 为 0/0/0；Firefox 控制台无 ChatGPT NET 运行时异常。
- [x] ZIP/XPI 只包含当前 1.5.0 运行文件，不包含 Baseline、测试、截图或历史安装包。
