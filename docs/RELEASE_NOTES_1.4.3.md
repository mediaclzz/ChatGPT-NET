# ChatGPT NET 1.4.3 发布说明

**发布日期：** 2026-08-09  
**需求基线：** 修订后的 ChatGPT NET Functional Baseline 1.3（仅第 83 条新增“同一子节点的多个父节点不得互为上下游”）

## 本次修正

- 建立单条或批量层级关系后，仅对本次关系所在的连通层级做结构排列；普通节点移动不触发自动排列，无关自由节点、其他连通分量及其合法线路保持原位。
- 纯树默认采用自上而下的组织结构图：父节点在上、同层兄弟横排、父节点相对直接子节点跨度居中，并逐层递归。
- 共同父节点的线路从父节点下边缘共用竖向主干，再沿同一条横向总线分叉到各子节点；无障碍时最多四个路径点，不再产生无意义绕远和折返。
- 超出有限画布宽度的极宽纯树改用从左到右的思维导图排列；多父 DAG 仍按拓扑层级自上而下排列，并通过稳定的重心排序减少交叉。
- 关系建立继续执行节点、线路、循环和多父独立性硬规则；无合法结构与线路时原子回滚。

排列原则参考了思维导图与组织结构图常见的 tidy-tree、分层和总线式正交连接思路，未引入第三方运行时或复制不适合本项目交互语义的编辑器代码。

## 性能与稳定性

- 排列仅在关系变化时计算一次，不挂接 animation frame、MutationObserver 或普通 pointermove。
- SVG 继续按关系 ID 增量复用；普通移动不会重绘无关关系，其他连通分量的线路坐标和 DOM 元素均保持不变。
- 31 节点代表性树排列设有低于 100 ms 的单元回归；当前 Chromium mock 中单条关系建立约 1–2 ms。
- 画布空白点击继续阻止事件传播，ChatGPT 正文滚动位置保持不变；画布与备忘录拖放及分组视觉回归保持通过。
