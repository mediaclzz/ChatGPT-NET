# ChatGPT NET 1.4.4 发布说明

**发布日期：** 2026-08-10  
**需求基线：** 修订后的 ChatGPT NET Functional Baseline 1.3；唯一文字修订仍为第 83 条的多父独立性规则。

## 修正的问题

1.4.3 的纯树排列正常，但无关节点挡住首选位置或新关系把两个树合并为多父 DAG 时，结构求解可能失败。随后旧的自由路由回退仍会提交关系，产生绕画布外圈、从子节点下方向上接入、层级错位等结果。

1.4.4 取消了这条错误回退：

- 新关系必须先得到完整的拓扑分层，任何父节点都位于子节点上方。
- 受影响层级以整体平移方式避开无关节点；候选位置来自附近偏移、障碍物四周边界和有限画布边界，无关节点不移动。
- 新建层级只能使用最多四个点的结构线路；共同父节点共享出线主干，共同子节点共享入线主干。
- 如果结构排列或结构线路无解，整个关系操作取消，不再调用 A* 绕远线路强行提交。
- 普通节点拖动仍保留原有稳定路由策略，不受“结构线路限定”影响。

## 验证

- 单元测试新增首选位置被两个无关节点占用的整组件换位场景。
- 单元测试新增两个根、六条关系、共享子节点和两层后代的多父 DAG；全部关系向下且路径不超过四点。
- 浏览器测试通过实际 `finishRelationDrop` 顺序建立同样的复杂多父结构，验证无关节点原位、关系原子性、Schema/Router 合法性及结构线路。
- 当前 Chromium mock 中连续建立上述六条复杂关系约 6.9 ms，单条普通关系约 2.0 ms。
- Chromium 视觉截图确认没有外圈绕线、回头线或父子层级倒置。
- `npm test` 继续覆盖 500 节点与 360 条关系压力场景。

Windows Firefox 与生产 ChatGPT 页面仍按 `MANUAL_ACCEPTANCE_1.3.md` 完成人工验收。
