# ChatGPT NET 1.4.5 发布说明

**发布日期：** 2026-08-10  
**需求基线：** 修订后的 ChatGPT NET Functional Baseline 1.3；唯一文字修订仍为第 83 条的多父独立性规则。

## 修正的问题

1.4.4 已保证“新建关系”使用树状排列，但旧版本保存的乱序坐标会原样载入；建立关系后再普通拖动已连线节点，也可能重新进入通用 A* 寻路，产生外圈大绕线、向上回接和无意义拐弯。

1.4.5 将结构规则覆盖到这两个入口：

- 带关系的旧画布第一次打开时，按弱连通组件分别做一次树状/DAG 分层整理，成功后写入布局版本标记，之后打开不重复排列。
- 迁移只改受影响的关系组件；备忘节点、无关自由节点和其他层级组件保持原位。
- 已连线节点拖动后，仅在父在上、子在下且结构短线可行时保留落点；否则对该关系组件重排，不再用外圈绕路补救。
- 依然保留多父节点的“多个上游不得互为上下游”规则和共享主干线。
- 备忘录标题高度从 34 px 减为 30 px；单行条目、分组标题、容器内边距及组间距统一压缩，保留分组左边框和“分组”徽标。

## 验证

- `npm test` 通过，包括 500 节点/360 关系压力路由。
- 真实 Chromium 浏览器全流程通过：构造旧乱序持久化布局后重新加载，所有关系恢复向下且路径最多四点，无关备忘节点坐标不变。
- 真实浏览器将多父子节点拖到上游上方，结果仍为合法自上而下的结构短线，没有接受外围绕线。
- 备忘录实际 DOM 像素检查：单行条目不高于 28 px，分组标题不高于 24 px，条目上下外边距合计不高于 4 px。
- 复杂六关系层级在当前 mock 浏览器中约 7.2 ms；20 次连续渲染约 1.4 ms。

Windows Firefox 与生产 ChatGPT 页面仍按 `MANUAL_ACCEPTANCE_1.3.md` 完成人工验收。
