# ChatGPT NET 1.4.6 发布说明

**发布日期：** 2026-08-12

**需求基线：** 修订后的 ChatGPT NET Functional Baseline 1.3；第 83 条记录多父独立性规则，第 205、206 条与 Manual Acceptance F88 按用户最终确认补充“图形合理优先、其次尽量减少重排”的层级整理规则。

## 本轮目标

用户无法继续手工验收，因此本轮按正式发布前验收处理：不只复跑现有测试，而是审查高频交互、资源生命周期、层级移动语义、恢复/撤回和大规模 DOM 表现，再在 Chromium 与 Firefox 中执行同一全流程。

## 发现并修正

- **分隔条拖动的完整重绘：** 旧实现在每个 `pointermove` 上重建节点、备忘录 DOM 并重新路由。现在只改两区的 flex 比例，释放时才保存。
- **节点 DOM 反复销毁：** 节点渲染改为按 `entityId` 复用 DOM；未变的 SVG polyline 继续复用。选择、Esc 清选、画布平移只同步 class/变换。
- **普通移动的整理优先级：** 先尝试用户落点和有界附近候选；若无法产生清晰的向下短线，仅重排被拖动节点所在的连通层级。无关自由节点、其他连通分量及其线路保持不动；连局部结构重排也无解时才原子取消。
- **孤立节点移动不必全图路由：** 只检查新矩形是否碰到现有线路，关系图和线坐标不变。
- **撤回/重做线路缓存：** 在写入前计算目标状态的合法线路，成功后同步替换缓存，避免后续渲染沿用另一历史状态。
- **旧布局局部无解：** 多个旧连通分量分别迁移；某一分量无结构解时保留它，不再阻断其他分量的修复。
- **高亮和窗口事件：** 备忘录内部滚动不再触发 ChatGPT 正文高亮重建；窗口 resize 合并到每帧一次，关闭 runtime 时取消未执行帧。
- **连线节点编辑/改宽：** 与普通移动一样使用结构短线校验，不会悄悄回退到长 A* 外围路线。
- **安装包无法加载脚本：** 旧构建使用 PowerShell `Compress-Archive`；在本机 Firefox 152 以临时附加组件安装时，manifest 能注册，但包内内容脚本均报 `Unable to load script`。构建现改用 Firefox 官方 `web-ext build`，同时输出同内容的 `.zip` 与 `.xpi`，真实 `chatgpt.com` 页面已能正常注入。
- **Firefox 版本边界：** 按用户确认，不再维持未实际验收的 Firefox 140 兼容承诺；manifest 最低版本调整为当前正式测试版本 Firefox 152。

## 验证证据

- `npm test`：全部通过，包括 500 节点/360 关系压力路由。
- Edge/Chromium 完整隔离浏览器全流程：通过。最终门禁复杂层级约 27 ms；360 节点下 100 次选择/平移热路径约 42.5 ms；10 次完整渲染约 25.3 ms。
- Playwright Firefox 完整隔离浏览器全流程：通过。最终门禁复杂层级约 40 ms；360 节点下 100 次热路径约 35 ms；10 次完整渲染约 37 ms。
- 本机正式 Firefox 152.0.4 + 当前真实 `chatgpt.com`：最终标准 XPI 能正常注入，侧栏固定在右侧、宽度 420 CSS px，画布与备忘录均挂载，ChatGPT 页面为侧栏预留空间；扩展控制台无错误。
- Firefox `web-ext lint`：0 errors、0 notices、0 warnings。
- 安装包内容校验：标准 ZIP/XPI 只包含 `manifest.json`、`background.js`、`icons/`、`src/`，不包含 1.3 文档、测试、截图或历史安装包。

## 仍属外部环境的边界

生产 ChatGPT DOM 可以随站点更新。正式 Firefox 的登录资料无法在不停机复制的最小 profile 中完整复现；生产页节点鼠标拖放也因 WebDriver/系统输入位于隔离桌面而无法自动重放，因此这部分由 Firefox 可见隔离窗口全流程覆盖，未伪报为“已登录历史会话实机鼠标验收”。真实 Branch in new chat、隐私窗口授权、Firefox 原生文件选择器和精确 10 分钟休眠仍保留在 `MANUAL_ACCEPTANCE_1.3.md` 中。
