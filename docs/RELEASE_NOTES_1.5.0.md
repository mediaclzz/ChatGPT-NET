# ChatGPT NET 1.5.0 发布说明

**发布日期：** 2026-08-12

**唯一产品需求基准：** ChatGPT NET Functional Baseline 1.5（并继承其中明确保留的 Baseline 1.3 规则）

**数据格式：** schema 1；新导出标记 Baseline 1.5；兼容导入 1.3、1.4、1.5

## 实现结果

- 空白画布释放固定解释为位置意图：自由节点、已解除节点和仍有关联的节点优先保留手动落点，只为被移动对象更新必要线路，不再因普通移动整理整个层级。
- 独立子树根节点按刚性整体移动，全部下游节点和内部线路保持同一平移量；存在外部多父连接时不会错误拉走共享下游。
- 单条、批量和新增多父关系在一次提交中自动排列完整受影响连通层级。布局固定为自上而下、同层横排、父节点居中，使用短正交共享主干；无合理有限画布解时原子失败。
- 关系释放的横向位置作为兄弟插入提示；既有兄弟顺序优先保持，批量节点使用操作前横向顺序、选择顺序、创建顺序作确定性回退。
- 自指、重复、循环、批量含已有父节点和多父祖先/后代冲突分别给出明确原因，不先运行昂贵布局搜索。
- 对话画布继续只按 `conversationId` 存储。项目形态 URL、项目名称和项目 ID 不参与画布键，也不触发复制或重置。
- 导出 baseline 更新为 1.5，schema 和 `chatgpt-net:v1:` 存储空间不变；历史 1.3/1.4 备份仍可严格验证后导入。

## 验证证据

- `npm test`：语法、静态基线、background、层级布局、核心数据/路由、500 节点和 360 关系压力测试全部通过。
- 本机 Firefox 152.0.4：使用 Mozilla geckodriver 0.37.1、独立临时 profile 和正式 `ChatGPT-NET-1.5.0.xpi`，在真实 `https://chatgpt.com/` 域完成注入和交互。
- Firefox 实测覆盖：孤立与关联节点手动落点、鼠标建立关系后的树状排列、关系一步撤回/重做、独立子树刚性平移、合法第二父、父节点祖先冲突原子拒绝、项目 A/B/移出三种路径、备忘录双向转换、正文滚动隔离。
- Firefox 资源快照：繁忙态工作集约 339 MB，5 秒后的空闲态约 340 MB；该空闲窗口只增加 0.078125 CPU 秒，未观察到持续 CPU 占用或扩展拖慢警告。
- `web-ext lint`：0 errors、0 notices、0 warnings。
- 包内容审计：ZIP/XPI 字节完全一致，SHA-256 `99D8C92E371632E4633F7474E101E19007869C467AE2694E23563E21F370F542`；只包含 `manifest.json`、`background.js`、`icons/` 和 `src/`，不包含历史版本或开发资料。

## 实机边界

项目迁移在真实 `chatgpt.com` 页和真实 XPI 中使用 `/g/project-a/c/<conversationId>` → `/g/project-b/c/<conversationId>` → `/c/<conversationId>` 三段站点路径验收；三次均核对同一实体集合与世界坐标。测试 profile 不复制用户日常 Firefox 登录资料，因此没有操作真实账户中的项目名称或服务器项目成员关系；插件实际只观察 `conversationId`，不读取项目数据。
